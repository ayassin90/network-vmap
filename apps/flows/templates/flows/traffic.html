Point your devices' NetFlow or IPFIX exporter at this server, UDP port 2055. Examples:

Cisco IOS-XE (Flexible NetFlow)

flow exporter VMAP
 destination <vmap-ip>
 transport udp 2055
 export-protocol netflow-v9
flow record VMAP
 match ipv4 source address
 match ipv4 destination address
 match ipv4 protocol
 match transport source-port
 match transport destination-port
 match interface input
 collect interface output
 collect counter bytes long
 collect counter packets long
flow monitor VMAP
 exporter VMAP
 record VMAP
interface TenGigabitEthernet1/0/24
 ip flow monitor VMAP input

Cisco NX-OS

feature netflow
flow exporter VMAP
  destination <vmap-ip> use-vrf management
  transport udp 2055
  version 9
flow monitor VMAP
  record netflow-original
  exporter VMAP
interface Ethernet1/49
  ip flow monitor VMAP input

Juniper (inline J-Flow / IPFIX)

set services flow-monitoring version-ipfix template VMAP ipv4-template
set forwarding-options sampling instance VMAP family inet output flow-server <vmap-ip> port 2055 version-ipfix template VMAP

Huawei (NetStream)

ip netstream export version 9
ip netstream export host <vmap-ip> 2055
interface XGigabitEthernet0/0/1
 ip netstream inbound
