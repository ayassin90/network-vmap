Writing templates

Lines are sent in configuration mode. Indent interface sub-commands with one space, as in the running config.

Values you list in the JSON box are asked for when the template is used: [{"name": "syslog", "label": "Syslog server"}], then write {% templatetag openvariable %} vars.syslog {% templatetag closevariable %}.

Device facts: {% templatetag openvariable %} device.hostname {% templatetag closevariable %}, device.site.name, device.mgmt_ip, device.model.

Ports: loop over interfaces.access, interfaces.trunk, interfaces.unused or interfaces.all:

{% templatetag openblock %} for i in interfaces.access {% templatetag closeblock %}
interface {% templatetag openvariable %} i.name {% templatetag closevariable %}
 spanning-tree bpduguard enable
{% templatetag openblock %} endfor {% templatetag closeblock %}

Use Preview on the change page to see the exact result for each device before anything is sent.
