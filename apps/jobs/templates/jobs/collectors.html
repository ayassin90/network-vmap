Collectors {% help 'collectors' %}

A collector is a small agent you run inside a network that this server cannot reach directly, for example when VMap is hosted in the cloud. It connects out over HTTPS, takes jobs for its devices, runs SSH and SNMP locally and sends the results back. No inbound firewall rule is needed.
