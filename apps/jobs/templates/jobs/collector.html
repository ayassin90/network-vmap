Run the agent {% help 'collectors#install' %}

On a small Linux VM or container host inside the network (2 vCPU, 1 GB RAM is plenty for hundreds of switches). It needs HTTPS out to this server, and SSH (22) / SNMP (161/udp) to the devices.

With Docker

docker run -d --name vmap-collector --restart unless-stopped \
  -e VMAP_URL={{ server }} \
  -e VMAP_TOKEN={% if token %}{{ token }}{% else %}<token>{% endif %} \
  vmap-collector:latest
# build the image once from the project:  docker build -t vmap-collector ./collector

Without Docker

pip install netmiko pysnmp requests
VMAP_URL={{ server }} VMAP_TOKEN={% if token %}{{ token }}{% else %}<token>{% endif %} python3 agent.py
# agent.py and executor.py are in the project's collector/ folder

Then point devices at this collector (device → Edit → Collector, or pick it when you start a discovery).
